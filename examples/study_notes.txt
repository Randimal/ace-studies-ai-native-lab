Introduction to Machine Learning

Machine learning fundamentals
Machine learning builds models that learn patterns from data to make predictions or find structure. Training fits a model using examples; inference applies the trained model to new inputs. A feature is an input attribute, such as house size. A label is the target, such as sale price. Parameters are learned during training. Hyperparameters, such as a tree's maximum depth, are settings chosen outside that fitting process. Training performance alone does not establish performance on new data.

Supervised learning
Supervised learning uses labeled examples. Classification predicts a category, such as spam or not spam. Regression predicts a numeric quantity, such as house price. A category coded as 0 or 1 is still a classification target. Linear regression models a numeric target as a weighted combination of inputs. Logistic regression, despite its name, is commonly used for classification. Decision trees use feature-based rules and can support classification or regression.

Unsupervised learning
Unsupervised learning finds structure without supplied target labels. Clustering groups similar examples, such as customers with similar buying behavior. K-means assigns points to cluster centers and updates those centers; the number of clusters is chosen in advance. Its results depend on feature scales and initialization. Dimensionality reduction represents data using fewer variables. Principal component analysis, or PCA, finds directions of high variance. High variance does not necessarily mean usefulness for a prediction task. Clusters do not automatically represent meaningful real-world categories.

Data preparation and splitting
Check missing values, duplicate records, inconsistent formats, and feature types. Numerical features may need scaling, especially for distance-based methods. Categorical features may need encoding. A training set fits parameters; a validation set guides model and hyperparameter choices; a test set estimates final performance on held-out examples. Fit preprocessing, including scaling and missing-value imputation, on training data only, then apply it to other splits. Data leakage occurs when information unavailable at prediction time influences training or evaluation. Time-dependent predictions may require chronological splits. Related records from one person may need to stay in the same split.

Overfitting and generalization
Generalization means performing well on unseen examples from the intended use setting. Overfitting captures training-specific detail or noise; a common symptom is strong training performance but weaker validation performance. Underfitting fails to capture useful structure and often performs poorly on both sets. Simpler models, regularization, or more representative training data can help reduce overfitting. Regularization discourages excessive complexity, but too much can cause underfitting. Cross-validation uses multiple training and validation splits to support model selection. Keep the final test set separate from this selection process.

Model evaluation
Accuracy is the proportion of correct classifications. It can mislead on imbalanced data: always predicting the majority class gives 95% accuracy when that class represents 95% of examples. For a chosen positive class, a true positive is a correctly predicted positive; a false positive is a negative predicted as positive; a false negative is a positive predicted as negative. Precision is true positives divided by all predicted positives. Recall is true positives divided by all actual positives. With 8 true positives, 2 false positives, and 4 false negatives, precision is 8/10 and recall is 8/12. F1 is their harmonic mean. For regression, mean absolute error averages absolute prediction errors; lower is better on the evaluated data. Choose metrics based on the consequences of errors and compare against a simple baseline. A held-out score does not guarantee future performance when the data distribution changes.
